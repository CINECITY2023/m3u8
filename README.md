# yt-m3u8-extractor

Una herramienta sencilla para extraer y guardar enlaces M3U8 desde videos o transmisiones en vivo de YouTube usando `yt-dlp`.

## 📦 Requisitos

- [`yt-dlp`](https://github.com/yt-dlp/yt-dlp)
- Python 3 (opcional, si usas el script en Python)
- Bash (si usas el script `.sh`)

## 🚀 Uso

### Opción 1: Script en Bash

```bash
./extraer_m3u8.sh https://www.youtube.com/watch?v=ID_DEL_VIDEO
